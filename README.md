# Gizemli Masal Atlası

Türk Masalları Derlemesi Web Sayfası — Programlamaya Giriş vize projesi
(İstanbul Medipol Üniversitesi, Görsel İletişim Tasarımı).

## Ne yapar?
On Türk masalını gece ormanı ve masal kitabı temasıyla tek bir sayfada toplar.
- Masal adına göre arama ve türe göre süzme (hayvan, büyü-gizem, insan hikâyesi)
- Yazı boyutu ayarı
- Masalı kapaklı, sayfa çevrilen bir kitap penceresinde okuma (düğmeler, ok tuşları, Esc)
- Bilgisayar ve telefona uyumlu düzen

Sayfa tek bir HTML dosyasıdır; CSS ve JavaScript dosyanın içindedir (içsel).
Harici dosya, yazı tipi veya kütüphane kullanılmaz, internetsiz çalışır.

## Nasıl açılır?
`index.html` dosyasını indirip çift tıklayın; herhangi bir tarayıcıda, internet olmadan da açılır.
Ya da aşağıdaki canlı sayfa bağlantısını kullanın.
